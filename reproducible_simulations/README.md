# Competition, Switching, and Control in Coupled Adoption-Opinion Dynamics

open it in MATLAB and run the script.

|---|---|---|

| `fig3_uniqueness` | `adop_multi_unique.m` (condition (9) holds), `adop_multi_nonunique.m` (condition (9) violated) | Fig. 3(a), 3(b) |
| `fig4_kingmaker` | `kingmaker.m` | Fig. 4 |
| `fig5-7_control` | `run_control_problems.m` | Figs. 5, 6, 7 |
